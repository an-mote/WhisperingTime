# 印迹 SwiftUI 界面设计规范

更新日期：2026-10-15。适用于 macOS 26+ 回顾优先原型。旧 Flutter ThemeData、Material 布局和枫叶 logo 不再作为当前实现约束。

## 信息与视觉方向

首页默认卡片回顾，内容是主要画面；工具栏切换四种展示，分类侧栏可收起。评估过固定目录、可收起目录与单条沉浸结构，采用可收起目录配内容画布；沉浸展示放入播放模式。应用不开屏自动播放。

采用 standard 原生风格：系统 Toolbar、Menu、Sheet、NavigationSplitView、语义颜色和 SF Symbols，系统字体中文回退为苹方。字体方案比较系统全无衬线、阅读区宋体、全局衬线三种，首轮采用系统字体保证阅读与控件一致。旧 logo 和候选稿全部移除，不增加新品牌标志。

## 共享尺度与样式

- 间距阶梯：4、8、12、16、24、32；阅读区最大行宽约720点，随窗口缩小。
- 字体层级：title／title2 表示页面、headline 表示内容摘要、body 表示正文、caption 表示辅助信息；由 NativeTypography 统一正文、标题、刻度和编辑文字，默认使用 SwiftUI 原生语义字体。字号增大时允许换行和滚动。
- 颜色角色：primary、secondary、windowBackground、controlBackground、separator、accent、error；系统明暗和高对比优先，不向每个页面散落颜色值。
- 卡片轻描边与有限圆角，避免每层都套面板；选中、错误、禁用、保存中均同时有文字或符号说明。

## 回顾和录入

默认隐藏绝对与相对日期；日历保留坐标。时间轴用内容顺序表达连续性，空白间隔等距收敛，不显示断签或缺席统计。切换展示、分类与选中项保持稳定。

录入先聚焦正文，标题和分类可选；图片、录音、刻度按需展开。录音权限仅在开始时申请。原声保存与转写独立；识别失败仍能回放、重试、手工输入。错误不清空草稿。

播放默认手动；长文滚动，声音不自动响起；播放声音时暂停自动翻页。应用失活暂停自动播放，减少动态效果时停用装饰转场。

## 窗口、输入与辅助功能

初始1000×760，最小640×480，验证1440×900宽窗口。根据容器大小重排网格和工具栏，窄窗口折叠菜单，不遮挡主要内容。弹窗正文滚动，保存／取消保持可达。

验收尺寸指内容视口，系统标题栏另计。macOS 的 Dynamic Type 环境值不改变文字大小；DEBUG 大字验收在窗口出现后通过 NSFont.preferredFont 获取语义字号并放大两倍，属于布局压力验证，不宣称支持 macOS 系统 Dynamic Type。[Apple说明](https://developer.apple.com/documentation/swiftui/environmentvalues/dynamictypesize)。

提供 Cmd-N、Cmd-S、方向键、空格和Esc；Tab焦点顺序符合阅读顺序，系统焦点环可见。分类操作有按钮和菜单替代拖动。图标按钮有中文 accessibilityLabel，装饰不重复朗读。

普通文字对比度至少4.5:1，大字及有意义控件至少3:1；状态不只靠颜色。跟随系统明暗、增加对比度、减少动画和减少透明度。VoiceOver 必须实际操作验证，语义树不替代屏幕阅读器验收。

## 状态与验收

覆盖空库、示例、长标题、长正文、多附件、未保存、保存中、失败、损坏库保护、无麦克风权限、转写准备／失败和模拟同步。保存或识别进行时防重复提交；离开前保护输入。

实际截图和交互覆盖最小／常规／宽窗口、明暗、大字、减少动态效果及对比度；不能以编译通过认定视觉合格。证据与未验证项见[SwiftUI原型验证](../../开发/SwiftUI原型验证.md)。
