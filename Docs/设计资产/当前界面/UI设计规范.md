# 印迹 SwiftUI 界面设计规范

更新日期：2026-10-16。适用于 macOS 26+ 回顾优先原型。旧 Flutter ThemeData、Material 布局和枫叶 logo 不再作为当前实现约束。

## 信息与视觉方向

首页默认卡片回顾，内容是主要画面；工具栏切换四种展示，分类侧栏可收起。评估过固定目录、可收起目录与单条沉浸结构，采用可收起目录配内容画布；沉浸展示放入播放模式。应用不开屏自动播放。

采用 standard 原生风格：系统 Toolbar、Menu、Sheet、NavigationSplitView、语义颜色和 SF Symbols，系统字体中文回退为苹方。字体方案比较系统全无衬线、阅读区宋体、全局衬线三种，首轮采用系统字体保证阅读与控件一致。旧 logo 和候选稿全部移除，不增加新品牌标志。

## 共享尺度与样式

- 间距阶梯：4、8、12、16、24、32；阅读区最大行宽约720点，随窗口缩小。
- 字体层级：title／title2 表示页面、headline 表示内容摘要、body 表示正文、caption 表示辅助信息；由 NativeTypography 统一正文、标题、刻度和编辑文字，默认使用 SwiftUI 原生语义字体。字号增大时允许换行和滚动。
- 颜色角色：primary、secondary、windowBackground、controlBackground、separator、accent、error；系统明暗和高对比优先，不向每个页面散落颜色值。
- 卡片轻描边与有限圆角，避免每层都套面板；选中、错误、禁用、保存中均同时有文字或符号说明。

## 回顾和录入

默认隐藏绝对与相对日期；日历保留坐标，时间轴底部保留导航所需的年月刻度。时间轴用内容顺序表达连续性，压缩无记录时段，不显示断签或缺席统计。切换展示、分类与选中项保持稳定。

录入先聚焦正文，标题和分类可选；图片、录音、刻度按需展开。录音权限仅在开始时申请。原声保存与转写独立；识别失败仍能回放、重试、手工输入。错误不清空草稿。

播放默认手动；长文滚动，声音不自动响起；播放声音时暂停自动翻页。应用失活暂停自动播放，减少动态效果时停用装饰转场。

### 时间轴画布与导航

- 时间从左向右推进，各分类共享时间横坐标。纵向按分类子树连续排列，兄弟子树依次展开，同级次序稳定；不得为了压低高度而穿插不同子树的分支和内容。多个顶层分类及未分类分别展开。
- 分类名称使用统一语义字号，靠近所属分支及首篇，不显示级别编号，不新增包围子树的分组框。以稳定排列、相邻位置和必要连线表达分类关系，不改变内容的时间坐标；不依赖颜色区分归属，不设置独立左侧分类栏或空白结构走廊，不以长引线隔开名称与内容。
- 每篇印迹只出现一次，每支首篇同时承担连接点与阅读入口，不增加独立空圆点。父子分类均有直属内容时，必须从父分类真实首篇卡片边缘分叉，直接连接子分类真实首篇卡片边缘；较早的子分类可向左回接，不改变内容日期，不以空白位置替代真实分叉点。
- 亲子连线优先采用局部短曲线，必要时沿所属子树边界的窄通道平滑转接，不交叉、交织、长段重合或穿过其他分支及内容。共同父节点处可有真实分叉，其归属须一眼可读；不靠更换线色掩盖纠缠。同分类后续内容采用简单平直的连接。
- 没有直属内容的祖先分类，以靠近后代的紧凑分类名称与位置表达归属，不添加分组框，不逐支绘制额外的关系缆线，不添加空内容点或额外长连线，不分配空内容行、不留悬空尾巴；后代也没有内容的分类不占画布。
- 节点使用系统语义字体、紧凑摘要和图片／声音线索；选中态有描边或符号，不能只靠颜色。长中文、长文和多附件通过换行、适配节点尺寸与完整阅读面板呈现，不裁切主要内容掩盖溢出。同时间的内容稳定错位，同支卡片不得重叠。紧凑排布必须服从稳定子树顺序、分类关系清楚和连线不交叉，不以压缩高度牺牲阅读顺序。
- 画布支持横向和纵向滚动。底部时间导航固定可见，使用原生 `NSScroller`；滑块宽度表达可见范围，拖动连续更新横向视口，触控板滚动反向同步滑块，保留纵向位置并避免回跳。不足一屏时停用横向导航。
- 年月刻度属于导航坐标，隐藏内容时间时仍显示。较早／较新按钮和键盘入口替代拖动，提供中文辅助标签与系统焦点环；装饰连接线不重复朗读。滚动不改变选中项，不自动打开内容。
- 保留分类范围、选中项与时间轴视口；从其他展示返回时，选中项有变化才定位该篇，否则恢复原位置，首次进入从最早内容开始。减少动态效果时直接定位和滚动，不依赖装饰动画解释分支关系；本轮不增加缩放及手动分支布局。

## 窗口、输入与辅助功能

初始1000×760，最小640×480，验证1440×900宽窗口。根据容器大小重排网格和工具栏，窄窗口折叠菜单，不遮挡主要内容。弹窗正文滚动，保存／取消保持可达。

验收尺寸指内容视口，系统标题栏另计。macOS 的 Dynamic Type 环境值不改变文字大小；DEBUG 大字验收在窗口出现后通过 NSFont.preferredFont 获取语义字号并放大两倍，属于布局压力验证，不宣称支持 macOS 系统 Dynamic Type。[Apple说明](https://developer.apple.com/documentation/swiftui/environmentvalues/dynamictypesize)。

提供 Cmd-N、Cmd-S、方向键、空格和Esc；Tab焦点顺序符合阅读顺序，系统焦点环可见。分类操作有按钮和菜单替代拖动。图标按钮有中文 accessibilityLabel，装饰不重复朗读。

普通文字对比度至少4.5:1，大字及有意义控件至少3:1；状态不只靠颜色。跟随系统明暗、增加对比度、减少动画和减少透明度。VoiceOver 必须实际操作验证，语义树不替代屏幕阅读器验收。

## 状态与验收

覆盖空库、示例、长标题、长正文、多附件、未保存、保存中、失败、损坏库保护、无麦克风权限、转写准备／失败和模拟同步。保存或识别进行时防重复提交；离开前保护输入。

时间轴另覆盖多个兄弟分类各有子孙的多层树、无直属内容的祖先、未分类、父子时间倒置、同时间多篇、长时间范围、分类移动与删除首篇后的重排；检查每篇唯一、同支卡片不重叠、有内容父子的分叉两端落在真实首篇、较早子类向左回接。完整窗口及实际显示尺度的截图须确认子树连续排列且顺序稳定、分类名称与所属分支邻近，没有级别编号或新增分组框，空祖先的名称和位置能对应后代，且没有为其逐支添加长关系线；同时检查线与线之间无非预期交叉、重合和绕入其他子树，不能只验证连线未穿卡片。整体构图须紧凑，没有独立左侧结构走廊、空祖先内容行或悬空尾巴，不能仅以节点和控件存在判定通过。实际操作底部拖动与画布滚动的双向同步、首尾可达、窗口缩放和展示／分类切换后的上下文，验证按钮、键盘、焦点、VoiceOver与减少动态效果。

实际截图和交互覆盖最小／常规／宽窗口、明暗、大字、减少动态效果及对比度；不能以编译通过认定视觉合格。证据与未验证项见[SwiftUI原型验证](../../开发/SwiftUI原型验证.md)。
