# 印迹 UI 设计规范

更新日期：2026-10-15。当前 Flutter 工程为 `App/WhisperingTime/`，界面保留已有“枫迹”品牌名称与正式枫叶标志。用户已确认视觉方向：温暖极简、米白底、枫叶橙、清晰排版。

## 设计目标

让记录内容成为视觉中心，让创建、浏览、筛选和编辑入口容易找到。页面采用留白、细描边和有限的品牌色，减少大图、阴影和装饰对阅读的干扰。欢迎页、工作区、记录卡片、编辑器与设置页共享同一套主题。

本次设计配合 UI/UX Pro Max 和 Design Master。通用设计检索未提供完全适合桌面生活记录产品的方案，因此实现以现有产品能力、已确认品牌与 Flutter 官方规范为依据：[自适应布局](https://docs.flutter.dev/ui/adaptive-responsive/best-practices)、[辅助功能](https://docs.flutter.dev/ui/accessibility-and-internationalization/accessibility)、[ThemeData](https://api.flutter.dev/flutter/material/ThemeData-class.html)。

## 色彩与主题

所有功能界面从 `ColorScheme`、`TextTheme` 与 `ImprintTokens` 读取语义颜色。主题定义位于 `lib/design/app_theme.dart`，采用 Material 3，并提供浅色、深色及高对比版本，跟随系统设置。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F8F5F0` | `#1B1917` |
| 内容面板 | `#FFFDFA` | `#25221F` |
| 辅助面板 | `#F0EAE2` | `#302B26` |
| 正文 | `#29231E` | `#F4EEE7` |
| 次要文字 | `#6D6055` | `#CCBEB1` |
| 主要操作 | `#963F24` | `#FFB38C` |
| 主要操作上的文字 | `#FFFFFF` | `#4B210F` |
| 辅助绿色 | `#506753` | `#B5C8B5` |

浅色主要操作色采用较深的枫叶橙棕，以保证白色按钮文字清晰；明亮枫叶色保留在标志与浅色品牌容器中。错误使用 `error/onErrorContainer`，成功使用 `secondaryContainer/onSecondaryContainer`；图标和文案共同表达状态。

核心文字组合的计算对比度：浅色正文与页面底色约 14.27:1、次要文字与面板约 5.99:1、主按钮约 6.92:1；深色对应约 13.74:1、8.72:1、7.93:1。高对比模式加强次要文字与边框。装饰性面板分隔线不作为唯一状态提示。

## 字体与尺度

当前采用平台系统字体，中文回退顺序为 PingFang SC、Microsoft YaHei、Noto Sans CJK SC、sans-serif。中文与拉丁字符均继承正式主题中的字体族，页面不得覆盖成测试字体。

后续字体选择可评估以下三个方向：

| 方向 | 适用范围 | 取舍 |
| --- | --- | --- |
| 平台系统字体（当前） | 导航、表单、正文 | 熟悉、无需额外下载，跨平台外观略有差异 |
| Noto Sans CJK SC | 跨平台统一界面 | 需核对授权、包体和完整中文覆盖后再引入 |
| Noto Serif CJK SC | 用户选择的长文阅读 | 可增强日记阅读感，表单和导航继续使用无衬线字体 |

正文为 14–16 逻辑像素，行高约 1.55–1.6；页面标题 26–32，欢迎页品牌标题 40。遵循系统文字缩放，不锁定字号。重要文案允许换行，长文限制行宽。

间距统一为 4、8、12、16、24、32、48。按钮圆角 14，面板圆角 18，弹窗与底部面板圆角 24。主要触控和图标按钮至少提供 48×48 的命中区域，输入焦点使用明显边框。

## 页面与交互

| 页面 | 规则 |
| --- | --- |
| 欢迎与账号 | 宽窗口分为品牌区与操作区，窄屏为可滚动单列；标志保持适度尺寸。游客访问为主要入口，账号入口次之。输入框有标签、密码显隐、自动填充、内联错误和提交中状态，切换登录注册保留输入。 |
| 工作区 | 宽度达到 900 时显示固定侧栏，较窄窗口使用抽屉。主题与分组名称可扫描，创建和管理入口可见，列表覆盖加载、失败、重试与空状态。 |
| 记录列表 | 卡片正文行宽受控，日期和等级为辅助信息；展开、编辑、设置提供明确按钮，不能只依赖滑动。 |
| 日历与筛选 | 显示记录数量、今天与定位入口；窄窗口减少嵌套边距，大字号需要时可以横向滚动。筛选面板可纵向滚动。 |
| 编辑器 | 标题、日期与等级、内容、量表分区；宽窗口内容最大宽度约 900。保存中避免重复提交，失败保留输入，退出等待已有保存任务完成。常规保存只持久化记录信息与刻度；现有图文／Markdown 正文不会恢复，因此标记为草稿，并提示离开页面后不会保留。 |
| 设置与反馈 | 操作使用统一面板、全宽输入与主题颜色。危险操作与普通操作分开表达；消息可换行，弹窗内容可滚动。 |

桌面初始窗口为 1000×760，最小窗口为 360×600。保留原生窗口背景和标题栏默认行为，避免透明窗口配置。返回、取消、确定与关闭遵循已有路由；异步更新必须检查组件生命周期，释放控制器、计时器和订阅。

图标使用统一 Material 图标，补充必要的 tooltip 和语义。视觉焦点、文本标签与选中样式共同表达控件状态。主题过渡为 180 ms，系统要求减少动画时停用主题过渡。

| 组件 | 状态与反馈 |
| --- | --- |
| 按钮 | 主次操作有明确层级；悬停、按下、键盘焦点沿用 Material 状态反馈；请求处理中禁用重复提交，并显示文案或进度。 |
| 输入框 | 始终保留标签；聚焦边框为 2 像素；错误和帮助文字允许多行；提交失败保留输入，提供重试。 |
| 内容列表 | 加载、空、错误与正常内容分别呈现；空状态给出下一步入口，错误状态提供重试。 |
| 设置面板 | 使用系统底部面板的单个拖动条；内容可滚动。显示优先在等待响应时禁用重复选择，失败恢复最后成功保存的选项。 |
| 消息 | 错误与成功采用对应语义容器、图标和文本；长消息使用可换行文本，不挤出窗口。 |

## 验证方式

从 Flutter 工程目录执行：

```bash
flutter analyze --no-pub
flutter test UIQA --no-pub
flutter build macos --debug --no-pub
```

`UIQA/` 直接渲染生产组件，使用内存样本覆盖小窗口、手机尺寸、横屏、宽窗口、浅色、深色及 2 倍文字，并验证适用的切换、展开、取消、表单校验和重试操作。PNG 输出到根目录 `TMP/UI重设计/2026-10-14/`。本机测试字体使用 STHeiti、Arial 与 Arial Unicode 补足 Flutter 测试环境；主题仍为生产 `AppTheme`，测试字体与实际系统显示可能存在字形差异。

这些渲染图属于生产 Flutter 组件在测试环境中的实际输出。它们不包含 macOS 原生标题栏，不替代真实设备、VoiceOver、性能或真实后端验收。实际账号提交、服务端读写、媒体上传和存储仍需相应环境下的端到端验证；本次验证结论以开发指南中的执行结果为准。
