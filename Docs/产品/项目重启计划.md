# 项目重启计划

更新日期：2026-10-15。产品重点调整为回顾，工程迁移为 SwiftUI；本轮交付独立本地交互原型，验收进度见[SwiftUI原型验证](../开发/SwiftUI原型验证.md)。

## 已确认的取舍

- 首轮 Mac 自用原型，macOS 26+；主页展示印迹，记录为次要但随时可达的入口。
- 卡片、日历、时间轴和应用内逐页播放共用回顾范围，默认隐藏时间。
- 任意层级分类树；每条印迹可不分类或归入一个分支。标题可空，默认写文字，按需添加图片、原声、转写和刻度。
- 本地保存测试内容；真实同步、内容加密、正式备份及旧数据导入不在本轮。没有重要历史数据需要迁移。
- 中转最长365天，全部目标设备可靠接收后提前删除；超期和新设备从已有完整设备或备份补齐。
- 删除 Flutter／Dart 全局工具链、对应缓存和旧 logo。保留 Go／proto、系统工具、用户容器和钥匙串。
- 在 develop 开发；AI扩展、社交、支付、多平台发布后排。

## 第一阶段：原型与迁移

更新产品和设计文档；实现四种回顾、分类整理、图文声及刻度补记、本机转写和本地持久化；验证 Mac 渲染、键盘、辅助功能和冷启动。形成源码快照后移除旧框架与产物，交付原型 DMG 和桌面替身。

通过标准：中文与附件重开一致；失败保留输入；分类删除不丢印迹；转写失败保留原声；播放可控；同步状态不伪装为真实服务。实际证据集中到[原型验证](../开发/SwiftUI原型验证.md)。

本轮26项原生自动化回归已通过，实际窗口和最终镜像资料重开核对已完成。当前实现已具备本地交互、图文声及刻度持久化、中文设备端转写、安装镜像和桌面替身，源码快照与框架清理已完成。麦克风实录因本机没有输入设备未验收，完整VoiceOver导航尚未通过；窗口显示的自动化与人工证据分别记录，不将所有验收项标为完成。

## 第二阶段：正式本地资料库

根据原型使用障碍确定最小范围，完成加密、密钥管理、草稿恢复和本地一致性快照备份。独立恢复必须核对正文、分类、图片、原声、转写、刻度、时间以及解密材料。失败不得覆盖已有资料。

旧 `.wtbackup` 使用旧主题／分组及 Quill 载荷；是否开发导入器另行决策，不因后缀相同宣称兼容。沿用旧验收思路，但必须有独立 Swift 测试和新格式版本。

## 第三阶段：真实中转同步

在本地资料库和备份可靠后，实现设备配对、密文增量、附件投递、持久化确认、冲突与墓碑、新设备快照、365天到期补齐和删除审计。现有 Go 长期存储 API 不作为新客户端数据源；协议调整单独评审。

验收至少覆盖三设备一台离线、确认前崩溃、图片／音频中断、重复乱序、并发修改、删除冲突、分类移动、新设备补齐期间编辑、撤销设备返回、过期缺口及最后确认后的清理。

## 真实试用

原型先用于体验测试；正式资料库完成独立备份恢复后，再依赖它保存真实长期记录。两周观察回顾能否找到上下文、四种展示各自用途、补记是否顺手、分类是否增加负担、语音和刻度是否有实际价值；不要求每天记录。
