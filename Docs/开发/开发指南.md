# 开发指南

更新日期：2026-10-15。日常开发分支为 develop；main 仅允许 git pull --ff-only。

## 原生客户端

工程位于 App/WhisperingTime/WhisperingTime.xcodeproj，scheme 为 WhisperingTime。最低 macOS26，Swift6，独立标识 com.acered.whisperingtime.prototype；不依赖 Flutter、Dart、CocoaPods 或第三方 Swift 包。

本地资料使用版本化 JSON 和附件，属于未加密测试原型；设备端语音转写使用系统 Speech，麦克风只在录音时申请。原型不接旧账号、钥匙串、Go、正式备份或真实同步。

SpeechTranscriber 还需检查硬件、语言和模型可用性，macOS 26+ 不等于所有设备均可识别。录音需要可用输入设备；无麦克风仍可导入音频。模型下载只由明确的“准备中文模型”操作触发，识别过程不上传原声。

停止录音后保留恢复文件；附件复制及印迹清单提交全部成功后才确认清理。失败保留原声，编辑器提供重试、在 Finder 查看和显式放弃。异步转写失败不撤销已保存音频，结果也不会直接覆盖用户修改过的转写。

使用已安装 Xcode 和 XcodeBuildMCP CLI。先检查 xcodebuildmcp --help 与对应命令 --help，工程不保存个人开发团队信息。Command Line Tools 被选中时，将 DEVELOPER_DIR 指向 /Applications/Xcode.app/Contents/Developer。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuildmcp macos build --project-path App/WhisperingTime/WhisperingTime.xcodeproj --scheme WhisperingTime --derived-data-path TMP/SwiftUI迁移/2026-10-15/DerivedData
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuildmcp macos test --project-path App/WhisperingTime/WhisperingTime.xcodeproj --scheme WhisperingTime --derived-data-path TMP/SwiftUI迁移/2026-10-15/DerivedData
```

Sources 保存入口、领域模型、LibraryStore、UI 和 Services；Tests 为持久化与语音单元测试；UITests 为生产应用交互回归。工程通过同步文件夹纳入源文件，无需逐项添加 build phase。

UI/NativeTypography.swift 集中语义字体，默认使用 SwiftUI 原生语义 Font，避免在应用初始化阶段主动解析 AppKit 字体。DEBUG 的 --qa-large-text 在窗口出现后通过 NSFont.preferredFont 注入2倍实际字号；这是排版压力测试，不能称为 macOS Dynamic Type 支持。字号压力矩阵已拆为独立UI测试，便于按场景复跑。界面自动化需独占桌面前台，避免与其他项目的XCTest或CUA并行。 指定QA尺寸的矩阵用例若启动后未呈现窗口，会通过NSWorkspace请求一次reopen再执行严格布局断言，并保留辅助记录；此类结果只证明已显示窗口，正常冷启动使用独立Release镜像核对。

资料保存在原型独立 Application Support 目录；沙盒发行包位于其独立容器内。--test-library 后跟稳定测试标识可在容器内使用隔离验收资料；--demo 只展示独立只读示例。不得把正式个人资料写入自动化夹具。

## 验证与安装包

构建、截图、语音夹具、日志和 DMG 都放在 TMP 对应任务目录。安装镜像是本机原型分发，不代表已公证或 App Store 发布。源码快照和本次实际清理证据见[SwiftUI原型验证](SwiftUI原型验证.md)。

签名核对使用 codesign --verify --deep --strict；通过文件类型检查确认包内不含 Flutter.framework 或 Dart 运行时。实际窗口需要检查最小640×480、常规与宽窗口、明暗、大字、键盘和 VoiceOver。

打包原型并更新桌面 Finder 替身，可在仓库根目录执行：

```sh
App/WhisperingTime/Scripts/package-dmg.sh
```

脚本以 Release 构建 Apple Silicon 本地包，核验签名与 DMG，并将真正的 Finder 替身保存到桌面“印迹 安装包.dmg”。产物在 TMP/安装包/日期/，不提交构建缓存。

## 历史 Go 服务

App/engine/ 及 App/proto/ 保留迁移前状态，包括此前未提交修复；本轮原型不连接、不重新部署，也不修改数据库。现有 PostgreSQL／MinIO 长期存储模型尚不满足“365天临时中转、全部接收后提前删除”。

如单独维护旧服务，在 App/engine/ 执行 Go 命令，数据库脚本为 ddl.sql。本机 config.yaml 按敏感配置处理，本轮不修改，也不加入源码快照、日志或示例；它已有的 Git 追踪状态未在本次迁移中调整。Go、PostgreSQL、Redis、MinIO 与共享 CocoaPods 未随 Flutter 卸载。

[记录可靠性验证](记录可靠性验证.md)与[备份恢复验证](备份恢复验证.md)仅为旧 Flutter 实现的历史证据。新原生备份、加密、密钥恢复和中转协议需要后续独立实现和验收。
