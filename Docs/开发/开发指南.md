# 开发指南

更新日期：2026-10-15。日常开发分支为 develop；main 仅允许 git pull --ff-only。

## 原生客户端

工程位于 App/WhisperingTime/WhisperingTime.xcodeproj，scheme 为 WhisperingTime。最低 macOS26，Swift6，独立标识 com.acered.whisperingtime.prototype；不依赖 Flutter、Dart、CocoaPods 或第三方 Swift 包。

共享 scheme 和同名汇总 target `WhisperingTime` 是统一构建入口：先构建内部应用 target `WhisperingTimeApp`，等系统签名完成后再核验、复制应用并更新桌面“印迹.app”Finder 替身。Xcode 的 Build／Run／Archive、Codex 的 XcodeBuildMCP 构建和打包脚本均经过此入口；即使没有源码变化，也会检查并重新创建替身。内部应用 target 仅负责生成产物，不作为独立交付入口。

本地资料使用版本化 JSON 和附件，属于未加密测试原型；设备端语音转写使用系统 Speech，麦克风只在录音时申请。原型不接旧账号、钥匙串、Go、正式备份或真实同步。

SpeechTranscriber 还需检查硬件、语言和模型可用性，macOS 26+ 不等于所有设备均可识别。录音需要可用输入设备；无麦克风仍可导入音频。模型下载只由明确的“准备中文模型”操作触发，识别过程不上传原声。

停止录音后保留恢复文件；附件复制及印迹清单提交全部成功后才确认清理。失败保留原声，编辑器提供重试、在 Finder 查看和显式放弃。异步转写失败不撤销已保存音频，结果也不会直接覆盖用户修改过的转写。

使用已安装 Xcode 和 XcodeBuildMCP CLI。先检查 xcodebuildmcp --help 与对应命令 --help，工程不保存个人开发团队信息。Command Line Tools 被选中时，将 DEVELOPER_DIR 指向 /Applications/Xcode.app/Contents/Developer。

```sh
App/WhisperingTime/Scripts/build-macos.sh
App/WhisperingTime/Scripts/build-macos.sh Release
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuildmcp macos build --project-path App/WhisperingTime/WhisperingTime.xcodeproj --scheme WhisperingTime --derived-data-path TMP/SwiftUI迁移/2026-10-15/DerivedData
App/WhisperingTime/Scripts/test-macos.sh Debug
```

Sources 保存入口、领域模型、LibraryStore、UI 和 Services；Tests 为持久化与语音单元测试；UITests 为生产应用交互回归。工程通过同步文件夹纳入源文件，无需逐项添加 build phase。

UI/NativeTypography.swift 集中语义字体，默认使用 SwiftUI 原生语义 Font，避免在应用初始化阶段主动解析 AppKit 字体。DEBUG 的 --qa-large-text 在窗口出现后通过 NSFont.preferredFont 注入2倍实际字号；这是排版压力测试，不能称为 macOS Dynamic Type 支持。字号压力矩阵已拆为独立UI测试，便于按场景复跑。界面自动化需独占桌面前台，避免与其他项目的XCTest或CUA并行。 指定QA尺寸的矩阵用例若启动后未呈现窗口，会通过NSWorkspace请求一次reopen再执行严格布局断言，并保留辅助记录；此类结果只证明已显示窗口，正常冷启动使用独立Release镜像核对。

自动化测试启动前通过 `Scripts/host-automation.py` 检查主机正在执行的测试；忙碌时打印占用进程并每三秒重查，直到空闲。常驻 `testmanagerd` 和排队中的 Xcode 构建前端不代表实际测试正在运行。`Scripts/test-macos.sh` 和 `Scripts/test-desktop-app.sh` 会持有同一用户的主机共享锁，锁覆盖子测试命令从启动到退出的整个过程；取消测试会先结束自己的子进程再释放锁，不会终止其他项目的测试。此脚本依赖 Python 3 标准库。

Xcode 共享 scheme 的 TestAction PreAction 也执行等待检查，并验证已有锁是否属于当前测试调用，避免自己等待自己。该前置步骤检查已有活动测试；脚本入口的共享锁额外防止同时发起的脚本请求竞争。直接在不同 Xcode 窗口从空闲状态同时启动测试仍存在检查后的竞争窗口，界面自动化应统一从 `test-macos.sh` 启动。其他项目若在本项目开始后绕过共享锁启动测试，本项目无法阻止它们。

只运行原生单元测试可执行：

```sh
App/WhisperingTime/Scripts/test-macos.sh Debug --json '{"extraArgs":["-only-testing:WhisperingTimeTests"]}'
```

其他自动化命令使用 `python3 App/WhisperingTime/Scripts/host-automation.py run -- <命令及参数>`；`test-macos.sh` 和 `test-desktop-app.sh` 已有保护，无需再次套用 `run`，重复包装会明确报错，避免等待自己的锁。主机排队逻辑的隔离回归入口为 `Scripts/test-host-automation.py`，通过同一 `run` 包装执行，夹具保留在 TMP。

2026-10-15 排队验证：外部 Python unittest 持续运行六秒时，原生测试入口等待两次、每次三秒，之后 17 项原生单元测试通过；1 项播放键盘 UI 冒烟测试通过，其执行期间后续请求保持等待，完成后才继续。21 项隔离回归覆盖进程识别、三秒重查、锁重入、重复包装、并发、取消、崩溃释放与退出码。桌面发布回归也已通过新入口运行，最终 Release 构建成功。证据见 [排队验证目录](../../TMP/自动化测试排队/2026-10-15/)。

资料保存在原型独立 Application Support 目录；沙盒发行包位于其独立容器内。--test-library 后跟稳定测试标识可在容器内使用隔离验收资料；--demo 只展示独立只读示例。不得把正式个人资料写入自动化夹具。

## 验证与安装包

构建、截图、语音夹具、日志和 DMG 都放在 TMP 对应任务目录。安装镜像是本机原型分发，不代表已公证或 App Store 发布。源码快照和本次实际清理证据见[SwiftUI原型验证](SwiftUI原型验证.md)。

桌面“印迹.app”是指向最近一次成功构建应用的真正 Finder 替身，可直接双击打开；“印迹 安装包.dmg”仍用于安装镜像。已签名应用的独立副本保存在 `TMP/本机构建/桌面应用/`，不依赖可被清理的 DerivedData。每次发布使用独立目录，并在签名与替身校验通过后原子替换桌面入口；构建或发布失败会保留之前的有效入口，同名普通文件不会被覆盖。发布脚本错误会使构建失败，不能静默跳过。

清理 TMP 时必须保留桌面替身当前指向的应用目录，以及仍在运行或需要回退的旧版本。若移动这些目录，须先成功构建以重新发布桌面入口。发布逻辑位于 `App/WhisperingTime/Scripts/update-desktop-app.swift`；隔离回归可执行 `App/WhisperingTime/Scripts/test-desktop-app.sh /path/to/WhisperingTime.app`，测试数据仅写入 TMP。

2026-10-15 本机验证：Debug、Release 与无源码变化的 Release 增量构建均自动更新了桌面替身；签名失败会让整个构建失败，旧替身字节保持不变。17 项原生单元测试通过，UI 测试宿主完成编译与签名，未运行完整 UI 测试。隔离回归覆盖替身创建与替换、坏签名、文件／目录／符号链接冲突及并发发布。最终 Release 副本通过严格签名检查，包内文件与最新产物逐项一致，并已通过桌面替身实际启动和核对窗口。证据见 [构建与测试目录](../../TMP/桌面替身验证/2026-10-15/)、[最终替身核对](../../TMP/桌面替身验证/2026-10-15/最终替身核对.json)。未在 Xcode 窗口单独执行构建；首次代理授权弹窗未做更改。

签名核对使用 codesign --verify --deep --strict；通过文件类型检查确认包内不含 Flutter.framework 或 Dart 运行时。实际窗口需要检查最小640×480、常规与宽窗口、明暗、大字、键盘和 VoiceOver。

打包原型并更新桌面 Finder 替身，可在仓库根目录执行：

```sh
App/WhisperingTime/Scripts/package-dmg.sh
```

脚本以 Release 构建 Apple Silicon 本地包，通过共享 scheme 自动更新桌面“印迹.app”，随后核验签名与 DMG，并将安装镜像的 Finder 替身保存到桌面“印迹 安装包.dmg”。产物在 TMP/安装包/日期/，不提交构建缓存。

## 历史 Go 服务

App/engine/ 及 App/proto/ 保留迁移前状态，包括此前未提交修复；本轮原型不连接、不重新部署，也不修改数据库。现有 PostgreSQL／MinIO 长期存储模型尚不满足“365天临时中转、全部接收后提前删除”。

如单独维护旧服务，在 App/engine/ 执行 Go 命令，数据库脚本为 ddl.sql。本机 config.yaml 按敏感配置处理，本轮不修改，也不加入源码快照、日志或示例；它已有的 Git 追踪状态未在本次迁移中调整。Go、PostgreSQL、Redis、MinIO 与共享 CocoaPods 未随 Flutter 卸载。

[记录可靠性验证](记录可靠性验证.md)与[备份恢复验证](备份恢复验证.md)仅为旧 Flutter 实现的历史证据。新原生备份、加密、密钥恢复和中转协议需要后续独立实现和验收。
