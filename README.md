# 印迹

回顾生活留下的印迹，需要时再补记。

印迹已迁移为回顾优先的 Mac SwiftUI 原型。首页以内容为主，提供卡片、日历、时间轴和逐页播放；默认隐藏时间，分类和标题均可选。

当前原型目标为 macOS 26+。测试资料仅保存在本机，包含文字、图片、录音、设备端转写和刻度。真实同步、内容加密、正式备份和旧数据导入尚未接入；同步页面是规则演示。
